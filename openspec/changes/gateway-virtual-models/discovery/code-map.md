# Code map

- `openspec/changes/gateway-virtual-models/specs/virtual-models/spec.md` (n/a (openspec change)) — symbols: Requirement. The requirements this map serves; no design.md or tasks.md exists beside it yet.
- `openspec/changes/gateway-virtual-models/manifest.md` (n/a (openspec change)) — symbols: tier, branch. Declares tier full and rules out routers and canvas as later features.
- `packages/contracts/src/gateway-config.ts` (n/a (contracts package)) — symbols: gatewayConfigSchema, GatewayConfig, virtualModelSchema, routingNodeSchema, targetSchema, RoutingNode, loadGatewayConfig, GATEWAY_CONFIG_VERSION, gatewaySlugSchema, slugFromName, gatewayPortSchema. The stored definition lives here; routingNodeSchema still admits a router arm the spec forbids, and targetSchema carries no account-kind refusal.
- `packages/contracts/src/accounts.ts` (n/a (contracts package)) — symbols: accountKindSchema, AccountKind, credentialedAccountKindSchema, CredentialedAccount, LocalAccount, SubscriptionAccount, Account, accountsDocumentSchema, loadAccountsDocument, ACCOUNTS_VERSION. The four account kinds a target picker reads; the subscription arm is the one the contract must refuse at parse.

EngineGateway carries only slug, displayName, and port today, so virtual models and credentials have no channel to the child until it widens.
- `packages/contracts/src/ipc.ts` (n/a (contracts package)) — symbols: ipcChannels, ipcResult, ipcErrorSchema, IpcError, IpcChannel, IpcRequest, IpcResponse, RecomposeIpc, ipcEvents. gateways:save already takes a whole gatewayConfigSchema, so a virtual model can reach disk without a new channel; no error code names a refused target kind.
- `packages/contracts/src/non-blank.ts` (n/a (contracts package)) — symbols: nonBlankString. The shared refusal for a blank id, accountId, or providerModel in a target.
- `packages/contracts/src/migration.ts` (n/a (contracts package)) — symbols: migrateDocument, Migration. Any narrowing of the stored routing shape past version 1 goes through this migration runner.
- `packages/contracts/src/index.ts` (n/a (contracts package)) — symbols: export * from './gateway-config', export * from './accounts', export * from './engine-protocol', export * from './ipc'. The single barrel every consumer imports from, so a new exported schema must land here to be reachable.
- `packages/engine/src/gateway-app.ts` (n/a (engine package)) — symbols: createGatewayApp, ANTHROPIC_MODEL_PATHS, OPENAI_MODEL_PATHS. The Hono app that 404s every model path today; the proxy from virtual name to target replaces those handlers.
- `packages/engine/src/refusals.ts` (n/a (engine package)) — symbols: missingModelInAnthropicDialect, missingModelInOpenAiDialect, unservedPath, nonLoopbackClient, requestCarriesOrigin. The typed refusal vocabulary to extend with unknown name, missing target, and missing credential in both dialects.
- `packages/engine/src/engine-runtime.ts` (n/a (engine package)) — symbols: createEngineRuntime, EngineRuntime, OpenListeners. start takes an EngineGateway and hands it to createGatewayApp, so the resolved targets enter the running gateway through this signature.
- `packages/engine/src/engine-child.ts` (n/a (engine package)) — symbols: attachEngineChild. Directive dispatch in the child; the probe arm passing a key to probeKey is the only precedent for a secret riding the message port instead of argv or env.
- `packages/engine/src/provider/key-probe.ts` (n/a (engine package)) — symbols: probeKey, firstPartyProbeOrigins. The existing outbound provider call with a credential in a header, and the origin table a proxy would reuse per provider.
- `packages/engine/src/provider/runtime-probe.ts` (n/a (engine package)) — symbols: probeRuntime. The loopback reach check for a local account, which a local target must satisfy before it can serve.
- `packages/engine/src/loopback-guard.ts` (n/a (engine package)) — symbols: guardLoopback. The middleware every proxied request still passes, so loopback-only and no-Origin hold on the new paths too.
- `packages/engine/src/gateway-listener.ts` (n/a (engine package)) — symbols: openGatewayListeners, GatewayListeners. Opens the port the proxied traffic arrives on; unchanged in shape but the path the new behaviour is reached through.
- `packages/engine/src/gateway-app.test.ts` (n/a (engine package)) — symbols: createGatewayApp. The behaviour spec asserting the current holds-no-virtual-model refusal; it changes when the proxy starts serving.
- `apps/desktop/src/main/engine-host/stored-gateway.ts` (n/a (electron main)) — symbols: storedEngineGateway. The single reader that builds the engine's view of a stored gateway, and the chokepoint that must resolve targets and pull credentials.
- `apps/desktop/src/main/engine-host/engine-host.ts` (n/a (electron main)) — symbols: createEngineHost, EngineHost, EngineHostDeps, EngineChild, DIRECTIVE_TIMEOUT_MS. Owns the child process and the directive round trip that would carry a gateway's targets and secrets.
