- `openspec/changes/provider-subscriptions/manifest.md` (openspec change artifact (outside FSD)) — symbols: none. GAP: the change folder holds only this manifest (tier full, phase discovery) plus discovery/, with no proposal.md, tasks.md, or specs/ delta, so no classifier path hints existed to resolve and the map below is derived from the two discovery briefs.
- `openspec/changes/provider-subscriptions/discovery/technical-research.md` (openspec change artifact (outside FSD)) — symbols: none. Names the vault string-vs-record decision, the accounts:connect shape mismatch, and the refresh-ownership conflict that drive most entries below.
- `openspec/changes/provider-subscriptions/discovery/acceptance-references.md` (openspec change artifact (outside FSD)) — symbols: none. Names the pass-through acceptance criteria that land on the engine package and the loopback-port constraint on any OAuth callback listener.
- `packages/contracts/src/accounts.ts` (contracts package (outside FSD)) — symbols: ACCOUNTS_VERSION, accountKindSchema, accountsDocumentSchema, AccountsDocument, loadAccountsDocument, defaultAccountsDocument. The account row: kind already carries subscription and aggregator, and credentialRef is the single string pointer an OAuth credential record has to fit through.
- `packages/contracts/src/ipc.ts` (contracts package (outside FSD)) — symbols: ipcErrorSchema, IpcError, ipcResult, connectAccountRequestSchema, systemStateSchema, SystemState, ipcChannels, IpcChannel, IpcRequest, IpcResponse, RecomposeIpc, ipcEvents, IpcEvent, IpcEventPayload, RecomposeIpcEvents. connectAccountRequestSchema demands a finished secret at call time, and ipcErrorSchema has no oauth-denied, oauth-timeout, or oauth-state-mismatch code, so any browser round-trip channel starts here.
- `packages/contracts/src/index.ts` (contracts package (outside FSD)) — symbols: none. Barrel that re-exports accounts and ipc, so any new OAuth module in contracts must be added here to reach main, preload, and the renderer.
- `packages/contracts/src/engine-protocol.ts` (contracts package (outside FSD)) — symbols: engineGatewaySchema, EngineGateway, directiveIdSchema, engineDirectiveSchema, EngineDirective, engineReportSchema, EngineReport. The start/stop directive union and the report that answers it; pushing a refreshed access token from main to the engine widens this discriminated union.
- `packages/contracts/src/gateway-config.ts` (contracts package (outside FSD)) — symbols: GATEWAY_CONFIG_VERSION, GATEWAY_PORT_RANGE, gatewayPortSchema, gatewaySlugSchema, slugFromName, RoutingNode, gatewayConfigSchema, GatewayConfig, loadGatewayConfig. The routing target inside virtualModels holds accountId, which is the only existing link between a stored account and the traffic a gateway would route through it.
- `packages/contracts/src/migration.ts` (contracts package (outside FSD)) — symbols: Migration, migrateDocument. The schema-version stepper every stored document runs through; a second vault or accounts version for OAuth records lands as a Migration here.
- `packages/contracts/src/non-blank.ts` (contracts package (outside FSD)) — symbols: nonBlankString. The trimmed non-empty string primitive that every account and credential field is built from.
- `apps/desktop/src/main/storage/vault.ts` (Electron main process (outside FSD)) — symbols: VaultDocument, VaultNewerSchemaError, loadVaultFile, saveVaultFile, setSecret, getSecret, deleteSecret. entries is Record<string, string> and the guard asserts typeof entry === 'string', so an access token plus refresh token plus expiry either serialises into one string or forces a vault schema version.
- `apps/desktop/src/main/storage/safe-storage-codec.ts` (Electron main process (outside FSD)) — symbols: SecretCodec, createSafeStorageCodec. The safeStorage encrypt/decrypt pair every vault write passes through, including the Linux plaintext fallback the briefs want surfaced for a refresh token.
- `apps/desktop/src/main/storage/vault-order.ts` (Electron main process (outside FSD)) — symbols: inVaultOrder. The single-writer queue that already serialises vault writes; a rotating refresh token needs to join this queue rather than write beside it.
- `apps/desktop/src/main/storage/one-at-a-time.ts` (Electron main process (outside FSD)) — symbols: OneAtATime, oneAtATime. The generic serialisation primitive inVaultOrder is built from, reusable for a refresh turn per account.
- `apps/desktop/src/main/storage/accounts-store.ts` (Electron main process (outside FSD)) — symbols: loadAccountsFile, saveAccountsFile. Reads and atomically writes accounts.json; an OAuth account row lands through these two functions.
- `apps/desktop/src/main/ipc/storage-ipc.ts` (Electron main process (outside FSD)) — symbols: StorageIpcHandlers, createStorageIpcHandlers. Holds the accounts:connect handler that mints cred-<uuid>, writes the secret, then appends the row; an OAuth connect splits this into begin-flow and finish-flow halves.
- `apps/desktop/src/main/ipc/storage-context.ts` (Electron main process (outside FSD)) — symbols: StorageIpcContext, StoragePaths, storagePathsFor, openVaultForWrite. The dependency seam handlers receive (getCodec, isEncryptionAvailable, startGateway) and the vault.bin/accounts.json path map an OAuth flow would extend.
- `apps/desktop/src/main/ipc/storage-envelope.ts` (Electron main process (outside FSD)) — symbols: ipcFailure, storageFailure, openVault. Builds the typed refusal envelope; new OAuth failure codes get their user-readable sentences here.
- `apps/desktop/src/main/ipc/dispatch.ts` (Electron main process (outside FSD)) — symbols: IpcHandlers, ipcChannelNames, dispatchIpc. ipcChannelNames is a hand-kept list parallel to ipcChannels, so every new OAuth channel must be added here or it is never registered.
- `apps/desktop/src/main/ipc/register-ipc.ts` (Electron main process (outside FSD)) — symbols: registerIpcHandlers. Binds each channel name to ipcMain.handle behind the trusted-sender check; the registration point for new channels.
- `apps/desktop/src/main/ipc/sender-trust.ts` (Electron main process (outside FSD)) — symbols: none. Guards which frame may invoke IPC; an OAuth callback must not become a second, unchecked entry into the handler set.
- `apps/desktop/src/main/ipc/engine-ipc.ts` (Electron main process (outside FSD)) — symbols: EngineIpcContext, EngineIpcHandlers, createEngineIpcHandlers. The engine lifecycle handlers and the port-offer path; a credential push to a running engine sits alongside these.
- `apps/desktop/src/main/windows/navigation-policy.ts` (Electron main process (outside FSD)) — symbols: NavigationPolicy, isAllowedNavigation, ExternalOpenDecision, decideExternalOpen. decideExternalOpen already returns open-https only for https URLs, which is exactly the predicate an authorization URL needs, and isAllowedNavigation already refuses the embedded-window path RFC 8252 forbids.
- `apps/desktop/src/main/windows/main-window.ts` (Electron main process (outside FSD)) — symbols: HOME_ROUTE, createMainWindow, showMainWindow, openSettingsSurface, openNewGatewaySurface, openGetStartedSurface. The only current caller of shell.openExternal, reached from setWindowOpenHandler; opening a browser from an IPC handler instead is the nameable extension the research flags.
- `apps/desktop/src/main/windows/permission-policy.ts` (Electron main process (outside FSD)) — symbols: allowsPermission. The one-permission allowlist a loopback OAuth flow must leave untouched, since it needs no web permission at all.
- `apps/desktop/src/main/index.ts` (Electron main process (outside FSD)) — symbols: none. Side-effect entry point that assembles every handler set and wires safeStorage, the engine host, and window creation; an OAuth handler set is composed here.
- `apps/desktop/src/main/engine-host/engine-host.ts` (Electron main process (outside FSD)) — symbols: DIRECTIVE_TIMEOUT_MS, EngineChild, EngineHostDeps, EngineHost, createEngineHost. Sends typed directives to the engine child and awaits a matching report; the transport a token push or a 401 callback would ride.
- `apps/desktop/src/main/engine-host/spawn-engine.ts` (Electron main process (outside FSD)) — symbols: spawnEngineChild. Forks the engine as a utilityProcess with no credential in the fork arguments today, which is the boundary ADR-0016 draws.
- `apps/desktop/src/main/engine-host/free-port.ts` (Electron main process (outside FSD)) — symbols: GATEWAY_PORT_BAND, offerFreePort. Pins the reserved 8389-to-8436 gateway band that an ephemeral OAuth loopback callback port must stay clear of.
- `apps/desktop/src/preload/index.ts` (Electron preload (outside FSD)) — symbols: none. Freezes one bridgeEntry per channel onto window.recompose, so every new OAuth channel needs an explicit line here.
- `apps/desktop/src/preload/index.d.ts` (Electron preload (outside FSD)) — symbols: none. Declares window.recompose and window.recomposeEvents from the contracts types; the only main-side file the renderer may reach.
- `packages/engine/src/gateway-app.ts` (engine package (outside FSD)) — symbols: createGatewayApp. Registers /health plus the four Anthropic and OpenAI model paths on Hono and 404s the rest; pass-through, header relay, and streaming all land here.
- `packages/engine/src/refusals.ts` (engine package (outside FSD)) — symbols: missingModelInAnthropicDialect, missingModelInOpenAiDialect, nonLoopbackClient, requestCarriesOrigin, unservedPath. recompose's own error envelopes; the acceptance brief requires these never wrap an upstream error body, so relay and refusal must stay separated.
- `packages/engine/src/loopback-guard.ts` (engine package (outside FSD)) — symbols: guardLoopback. Refuses any host outside 127.0.0.1, localhost, [::1] and any request carrying Origin; the only thing standing between a loopback caller and subscription quota until a token gate lands.
- `packages/engine/src/engine-runtime.ts` (engine package (outside FSD)) — symbols: OpenListeners, EngineRuntime, createEngineRuntime. Serialises start and stop per gateway and holds the registry of open listeners; a per-gateway credential would live beside that registry.
- `packages/engine/src/gateway-listener.ts` (engine package (outside FSD)) — symbols: GatewayListeners, openGatewayListeners. Binds IPv4 and IPv6 loopback and reports port-taken; the streaming promise in the acceptance criteria is measured against this Node adapter.
